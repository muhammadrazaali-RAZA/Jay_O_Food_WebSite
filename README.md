# Jay O Food – Interactive Restaurant Website

## Project Overview
Jay O Food is a fully interactive restaurant website developed from scratch, showcasing both frontend and backend engineering. The project demonstrates strong software development skills and complete ownership of the design, implementation, and deployment process.

## Technologies Used
- **Frontend:** CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  

## Key Features
-  **Table Reservation System** – Customers can book tables online.  
-  **Event Management** – Create and manage restaurant events.  
-  **Online Store** – Integrated e-commerce functionality for food ordering.  
-  **Responsive Menu** – Mobile-friendly design for seamless browsing.
